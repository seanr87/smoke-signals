# Round 5b check: where every number comes from

Batch `output/20261117-230933`. Scripts run as `python -I -X utf8 <script>` from their own folder. The batch folder is not in
git; `batch.json` names it and, in a second working folder, the checkout that holds `output/`.

## How the Round 5 numbers were re-established

1. **Same definitions, new batch.** Every Round 5 script was rerun on the new batch (`run_round5_scripts.sh`) and every
   output compared with the Round 5 copy (`compare_with_round5.py`, result in `rerun/same-definitions.txt`). 30 of 33 files
   are identical. The other three (`part-d/clan_styles.json`, `d1_scores.json`, `d1_tables.md`) and two lines of the Loop
   Daring script output differ only in the order in which ships with equal counts are listed. No number moved.
2. **Clock fix.** `r5lib.py` then gained the 15-minute-clock correction and the scripts were rerun. Every changed output
   line is in `rerun/clock-fix-changes.md` (`clock_fix_changes.py`).
3. **New data.** Items redone from the timelines are in `new-n1` to `new-n4`, each with its own check table below.
